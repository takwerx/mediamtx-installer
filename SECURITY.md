# Security

## Reporting a vulnerability

Please report it privately: open this repository's **Security** tab and choose
**Report a vulnerability**
([direct link](https://github.com/takwerx/mediamtx-installer/security/advisories/new)).
Do not open a public issue, and do not post details, logs or proof-of-concept
data where others can read them.

## Supported versions

Only the latest release (the `main` channel) gets security fixes. Update before reporting.

## What to expect

We acknowledge a report within 3 working days, tell you whether we can
reproduce it, and keep you updated until a fix ships. Confirmed issues are
fixed in a new release and credited to you if you want.

## Scope

The installer scripts, the web console (`config-editor`) and how they configure MediaMTX, including authentication, the API port and generated credentials. Vulnerabilities in MediaMTX itself belong with the upstream project.
