# Security

## Reporting a security problem

Do not report vulnerabilities, CVEs, exploits, leaked keys or passwords in public
issues, discussions or pull requests. Email **takwerx@gmail.com** instead. Include
what is affected, the version, and how to reproduce it. If you have a fix, attach
or describe it.

## Supported versions

Only the latest release (the `main` channel) gets security fixes. Update before reporting.

## What to expect

We reply within 3 working days, work with you privately until a fix ships, and
credit you if you want. Please do not disclose it publicly until a fix is released.

## Scope

The installer scripts, the web console (`config-editor`) and how they configure MediaMTX, including authentication, the API port and generated credentials. Vulnerabilities in MediaMTX itself belong with the upstream project.
